## How to use this index

Update `Status` in place when a risk changes state (`OPEN` →
`RESOLVED`/`CLOSED`/`MITIGATED`) — keep resolved rows visible with their
resolution noted, per this project's "never silently overwrite history"
rule, rather than deleting them once closed.

See also [`docs/open-questions.md`](open-questions.md) for unresolved
questions needing a decision, as distinct from risks tracked here.
