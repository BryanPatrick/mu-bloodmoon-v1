3. GENUINE OBSERVATION (not a bug in this phase's code, flagged for
   awareness): aaaa/Elfa/summoner/RFRF all show Experience = -472819216, a
   negative value. Experience is stored as SQL Server `int` (32-bit
   signed) on the real Character table; CharacterCore.Experience is
   likewise a C# `int`. A cLevel=400 character's real experience value
   exceeds Int32.MaxValue (2147483647) and has wrapped around during
   storage/accumulation on the game server's own side -- this is a
   pre-existing real-data condition on the live server, not something
   introduced by GameBridge's read path (GameBridge only reads the column
   as-is via SqlDataReader.GetInt32, matching the column's real SQL type
   exactly). Documented here as new real-data evidence; no type change
   made this phase (would be a schema-contract change beyond Phase 2B's
   read-only scope).
