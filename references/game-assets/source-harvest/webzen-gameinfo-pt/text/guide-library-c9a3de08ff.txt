 Rune Mage Buff Skills
 1. Introduction
 1) Rune Mage Buff Skill - Burst, Haste (1) Added two Rune Mage specific buff skills.
 Rune Mage-specific Buff Skill
 Reinforce: Burst Reinforce: Haste
 * Two or more &lsquo;reinforce&rsquo; buffs cannot be used at the same time.
 &lsquo;Reinforce&rsquo; buff skills share the cooldown.
[Reinforce: Burst] Skill name Reinforce: Burst
 Requirement Level 200
 Description The Reinforce: Burst is a buff skill that can be learned from a skill tome when the Rune Mage reaches level 200.
This skill affects only the caster.
When Reinforce: Burst is used, skill damage and MP cost are increased for the duration.
 Skill Use Level Lv 200 ~
 Other Setting Cooldown: 60 sec
Duration: 15 sec
 Skill Image and Description
 MST Reinforce Increases the duration of Reinforce: Burst by %d sec. (Point : 1/20)
 Mastery Decreases the cooldown of Reinforce: Burst by %d sec. (Point : 1/20)
[Reinforce: Haste] Skill name Reinforce: Haste
 Requirement Level 400
 Description The Reinforce: Haste is a buff skill that can be learned from a skill tome when the Rune Mage reaches level 400.
This skill affects only the caster.
When Reinforce: Haste is used, Attack Speed and AG cost are increased for the duration.
 Skill Use Level Lv 400 ~
 Other Setting Cooldown: 60 sec
Duration: 15 sec
 Skill Image and Description
 MST Reinforce Increases the duration of Reinforce: Haste by %d sec. (Point : 1/20)
 Mastery Decreases the cooldown of Reinforce: Haste by %d sec. (Point : 1/20)
