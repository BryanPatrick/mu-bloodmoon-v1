 1. Skill
 1) White Wizard: Kundun Mephis
 (1) White Wizard: Kundun uses some skills of the Dark Wizard and some exclusive skills.
 Shared Skills
 Earth Prison, Illusion, Hell Burst, Telekinesis, Magic Amplification,
 Power Wave, Lightning, Teleport, Ice, Tornado, Aqua Beam, Blast
 Exclusive Skill
 Magical Shot
 Shining Bird
 Violent Dragon
 Spearstorm
 Reflective Barrier
 [Magical Shot]
 Skill Name
 Magical Shot
 Skill Requirements
 Acquired upon Character Creation
 Skill Description
 Throws an enchanted projectile, dealing damage to the target.
  Targets affected by the projectile receive damage twice.
 Misc Settings
 Cooldown:  None
 Skill Image

 Skill Name
 Shining Bird
 Skill Requirements

 [Spearstorm]
 Skill Name
 Spearstorm
 Skill Requirements
 Energy: 1160
  Violent Dragon Mastery 10P
 Skill Description

  by firing a spear of light.
  Affected Targets receive DMG twice and also
  an additional instance with a 5% chance.
 Misc Settings
 Cooldown:  0.5 seconds
 Skill Image
 [Reflective Barrier]
 Skill Name
 Reflective Barrier
 Skill Requirements
 Energy: 410
 Skill Description
 Creates a reflective barrier for you or your allies that
  blocks DMG and returns a portion when receiving Shock DMG.
 Misc Settings
 Cooldown:  None
 Buff Applied to: All Party Members including Self
 * The Buff does not stack with the Summoner's "DMG Reflection" Skill

 Skill Name
 Unleash Marble
 Skill Requirements
 Energy: 700
 Skill Description

  for a period of time.

 Misc Settings
 Cooldown:  10 seconds
 Duration: 30 seconds
 DMG: 2 instances of DMG per second

 2. Equippable Weapons
 1) White Wizard: Kundun Mephis
 (1) Can Equip the Dark Wizard's "Staff" as the Main Weapon
     and the "Magic Book" as the Sub Weapon.
 2) Mage: Lemuria
 (1) Can Equip the "Orb" as the Main Weapon
     and the Dark Wizard's "Shield" simultaneously as support.
 3. Item
 1) Low-Level Equipment, Skill Grimoire NPCs
 (1) Low-Level Equipment and Skill Grimoires for Kundun and Lemuria 
     can be bought in Town from NPCs.

 ② Skill Grimoires: Madam Liamann (Lorencia 125, 133)
