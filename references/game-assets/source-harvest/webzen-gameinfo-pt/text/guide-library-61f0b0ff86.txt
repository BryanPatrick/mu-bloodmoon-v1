 4.  Legendary Equipment Upgrade
   1) Legendary Excellent Armor Upgrade Settings
    (1) Excellent Temple Guard Armor dropped from hunting grounds can be upgraded in the same way as existing equipment upgrade.
  2) Legendary Set  Armor Upgrade Settings
   (1) New Option Settings for Legendary Set Equipment
    ① ‘Upgrade Level’ and ‘Upgrade Stage’ have been created for Legendary Set equipment,
         and settings for Upgrade conditions and Success/Failure of Upgrade have been added and changed.
   [Upgrade Stage]
 Upgrade Options
 Stages
 New stages from 1 to 5 have been applied for each equipment's upgrade level.
 Upgrade Option Effect
 Depending on the equipment, stage-specific option effects are applied.
 (Example: Temple Guard Sword - ATK Increase / Temple Guard Staff - Wizardry Increase)
   [Upgrade Level]
 Upgrade Level
 Stages
 Each piece of equipment has levels 0 to 15.
 Upgrade Level Effect
 Basic Attributes increase depending on equipment.
 The increase options according to the Upgrade level are the same as the existing settings.
   2) Legendary Set Equipment Upgrade Settings
    ① You can strengthen legendary equipment through [Equipment Upgrade/Crafting] – [Equipment Upgrade], Elite Equipment Upgrade] of Noria NPC Chaos Goblin.
    ② Depending on the Upgrade status of the equipment registered as the main material, [Upgrade Stage] and [Upgrade Level] increase.
   [Legendary Equipment Upgrade Settings]
 Upgrade Level
 Registered Upgrade Equipment
 If the registered main material is at Upgrade Lv. 14 or lower and the Upgrade option is stage 5,
 the level will be upgraded.
 Upon Success
 The Upgrade level increases by 1 level, and the Upgrade option becomes stage 1.
 Upon Failure
 The Upgrade level is maintained, and the Upgrade option becomes stage 1.
 Upgrade Options
 Registered Upgrade Equipment
 If the registered main material equipment is at stage 1 to 4, the stage of the Upgrade option will go up.
 Upon Success
 Upgrade option will go up 1 stage.
 Upon Failure
 Upgrade option will go down 1 stage.
  - It will not drop below level 1.

   ♣ Upgrade Options
 [Upon Success]  Upgrade option will go up 1 stage.
 [Upon Failure] Upgrade option will go down 1 stage.
   e.g.) If you are in Upgrade Level 0 - Stage 3,
     a) upon success, you will be Level 0 - Stage 4
     b) upon failure, you will be level 0 - Stage 2
 ♣ Upgrade Level
 [Upon Success]  Upgrade level increases by 1 level, and the Upgrade option becomes stage 1.
 [Upon Failure]  Upgrade level is maintained, and the Upgrade option becomes stage 1.
   e.g.) If you are in Upgrade Level 1 - Stage 5,
     a) upon success, you will be Level 2 - Stage 1
     b) upon failure, you will be level 1 - Stage 1

 5. Additions and changes in Legendary Equipment Options
  1) New options and changes to Legendary Equipment
   1) Weapon Attack Success Chance
    ① Attack Success Chance option has been added as a basic attribute to Legendary Set Weapon items.
    ② The Attack Success Chance option value increases as the Upgrade level increases.
   (2) Change in Set Defense Option
    ① The Set Defense that increases when wearing the same armor has been changed from a ‘%’ option to a ‘value’ option.
