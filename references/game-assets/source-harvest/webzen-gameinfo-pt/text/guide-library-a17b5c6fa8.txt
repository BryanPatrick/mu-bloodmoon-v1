 A. New Equipment Artifact
 1. Artifact Introduction
 1) New Artifact that can be equipped by character has been added.
 2. Artifact
 1) Settings
 (1) Artifact is an Equipment Item that characters can equip.
 (2) There is an exclusive slot for Artifacts.
      Equip the Artifact to the slot to have the Artifact option effect applied.
 (3) Artifact is shaped like a puzzle with hexagon linked together and there are several types.
 (4) Artifact type can be differentiated by looking at the number of Hexagons attached to it.
      (Example: 1 Hexagon attached means Type 1 / 2 Hexagon means Type 2.)
 (5) Artifact can be upgraded up to 15 times.
      ① Talk to 'Chaos Goblin NPC' at Noria map for upgrade.
      ② Item will not be destroyed when upgrade fails, but will revert to Enhancement +1.

 3) Equipping Artifact
 (1) Equip at Artifact Slot UI window.
 (2) Click the Artifact button in the Inventory Window to open the UI.
 (3) At the Artifact Slot UI Window, drag and drop the Artifact item
 from your Inventory to equip.
 ① Artifact and Slot type must match to equip.
 (Example: Only Spider Artifact can be equipped in Spider Artifact Slot.)
 ② Cannot equip more than 1 of the same type of Artifact in the slot.
 (Example: Cannot equip more than 1 of the type 1 artifact.)
 (4) Equip all Artifact Slot with Artifacts to activate 'Full Set Option'.

 4) How to acquire Artifact
 (1) Artifact can be acquired through combination using 'Artifact Fragment' as material.
      ① Artifact Fragment can be acquired at 'Baruka' event map as  clear reward.
 (2) Talk to 'Chaos Goblin' NPC at Noria for combination.
      - All Materials disappear when combination fail.
      - Up to 30 can be created at once using 'Mass Combining'
