 Classes undergoing character renewal will have their Combat Power(%) attribute newly applied to display stronger attack.
 Combat Power(%) attribute can be increased with Stat Points, Weapon and Item option increase for the character undergoing renewal.
 1. Combat Power(%) Attribute Display
 1) Character Information Window and Weapon Item Option Display Information
 - Combat Power(%) is decided by the stat points of each class and equipping item with Combat Power(%) increase option will increase Combat Power(%) of the character.
   The combined Combat Power(%) will be display accordingly in the Character Information window.
 2) Character ATK and Skillpower Increase
 - Character's Combat power(%) will proportionally increase character's ATK and Skillpower.
 - Combat Power(%) is only applied to attacking skills.
