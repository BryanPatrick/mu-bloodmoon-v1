 Wings Combination Improvements
 1. Wing & Cape Craft Combination Convenience Improvements
 - Craft Wing items via Noria NPC 'Chaos Goblin' [Equipment Upgrade/Craft] menu.
 2.  Chaos Goblin Equipment Craft/Upgrade
 - Noria NPC 'Chaos Goblin' (180, 102) click on [Equipment Upgrade/Craft] button to load Goblin Combination Page.
 3. Goblin Combination Page UI
 1) Wings(Cape) Craft Menu
 - Click on [Wings(Cape) Craft] to load Wing Craft menu.
 - View default setting for Wing(Cape) and click on Craft Wing
   to view combination settings and combination materials page.

 3) Crafting Wings(Cape)
 - For materials with (+), (-) buttons, use the button to register how many materials will be used.
 - For all Wing Combination, register main items from the Help page to automatically
   have other required items from the inventory registered.
 4. Wing & Cape Combination Setting
 - Detailed combination setting and combination material settings can be viewed at [Wing(Cape) Craft] UI.
 - Wing(Cape) item of random class is crafted upon successful Wing(Cape) combination.

 6. Other Combination Setting Changes
 1) Rexmilon's Seal
 - Cannot use Rexmilon's Seal as combination material when crafting Lv. 2 Wing item.
 - Rexmilon's Seal will no longer drop from monsters.
 2) Condor's Feather and Garuda's Feathers Setting Changes
 - Combination to craft Condor's Feather and Garuda's Feathers have been removed.
 3) Lv. 4 Wings(Cape) Combination Result Setting Changes
 - Wing(Cape) item of random class is crafted when crafting Lv. 4 Wing(Cape).
 4) Other Setting Changes
 - Changes have been made to materials required for Wing Crafting.
 - Check the Combination UI Help Page to view detailed information about combination material.
