 2) Ancient Lightning Set   Upgrade New Combination Material – Lightning Soul
 - The new Combination Material “Lightning Soul” for Upgrading Apocalypse Set Items.
 - "Lightning Soul" can be purchased from Elveland NPC James for 50,000 Ruud.
 3) Ancient Lightning Crafting
 - Ancient Lightning Set Items can be upgraded by combining Apocalypse Armor with level +11/16 options or higher with combination material.
 - When upgrading to the 'Ancient Lightning Set' item, the equipped class, equipped part, luck option, and all stat options are maintained.
