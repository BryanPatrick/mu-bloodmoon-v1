 A. Elf Renewal Update Overview
 1. Elf Renewal
   1) Elf Build Type
 Build Type
 Description
 Attack-Type Elf
 Dexterity Stat focused build.
 Quicker attacks and uses stronger skills.
 Support-Type Elf
 Energy Stat focused build that use Buff Skills to support party members.
 Learn new Buff Skill and equip exclusive shield
 2. Attack-Type Elf
   1) Weapon Attack Speed and Stat Attack Speed Increased
     (1) Elf's Crossbow, Bow and Quiver attack speed has been increased.
     (2) Attack speed affected by Elf's stat has been increased.
   2) Weapon Durability loss reduced
     (1) Elf's Crossbow and Bow durability loss rate has been slightly reduced.
   3) New Buff Skill Added
     (1) Dex Booster
 Dex Booster
 Acquired from
 Elveland NPC - Buy from Priest James for 1,000 Ruud
 Skill Description
 Requirement to learn skill: High Elf, 500 Dexterity
 Buff Duration: 300 Seconds
 Increases your movement speed, attack speed, and attack success rate for a certain period of time.

 4. Other
   1) Addition of MU Helper Settings (Elf)
     (1) Buff Register Slot Added
     ① 2 additional Buff Register Slot add for Elf.
     a) Previous 4 Slots -> Changed to 6 Slots
     (2) Heal support setting added
     ① Setting has been added to select from Healing or Party Healing.
     ② Go to 'Party Support > Auto Recovery Setting > Skill Activation' to select.
     ③ In 'Skill Activation' window
     You can register Heal, Party Heal skill in 'Default Skill', 'Activation Skill' slot
     a) You can only register Heal and Party Heal skill once they have been added to Skill Imprint tab
