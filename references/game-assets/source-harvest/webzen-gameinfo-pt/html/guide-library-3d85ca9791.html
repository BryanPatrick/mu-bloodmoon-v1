3) Wing Core Upgrades


- A Wing Core can be Upgraded up to Level 15.

- Wing Cores can be Upgraded through Equipment Upgrade Combination at the “Chaos Goblin NPC” in Noria.

- Wing Core Upgrade Levels Decrease by 1 on Failure for Levels 1 - 7, and Reset completely for Levels 8 - 15.

- Wing Cores ARE NOT destroyed on Failure.

4) How to Equip/Unequip Wing Cores


- Wing Cores can be Equipped/Unequipped through the Lv. 5 Wings UI Screen.

- The “Lv. 5 Wings(Cape) UI” opens when “Alt + Right-Clicking” a Lv. 5 Wings(Cape) in your Inventory.

- “Drag-and-Drop” Lv. 5 Wings in the Inventory in the UI to Equip them.

- Wing Cores can only be Equipped/Unequipped on Lv. 5 Wings in the Inventory, and not on those currently Equipped.

- “Right-Click” or “Drag-and-Drop” “Wing Cores”  from the UI to the Inventory to Unequip them.
