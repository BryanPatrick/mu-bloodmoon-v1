1. Character Attributes Setting Changes

1) Stats Setting Changes

Changes in Attributes through Stats

The (Min/Max) attack, attack success rate,
 and skillpower (%) attributes using stat points have been changed.

Changes in Attack Speed

Max attack speed has been changed to 290,
 and character animation speed according to attack speed has been changed.

Addition of Combat Power (%) option

You can use your character's stat points, weapon items,
 and buff skills to enhance your combat power (%) options.
