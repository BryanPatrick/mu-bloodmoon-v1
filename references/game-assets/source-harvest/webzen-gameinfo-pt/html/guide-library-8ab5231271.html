Ability Upgrades

After the 5th Class Advancement, character can be further strengthened 

by crafting Ability Cards by using Ability Crystals and equipping the cards in Ability Upgrade Core ' Slots.


1. New Abilities


- Characters get access to new Abilities upon 5th Advancement.


New Abilities

Description

Extra DMG

Characters get 3 Types of new DMG - Nuke, Bolt, and Wide.
 They Activate when Using Upgrade Skills (4th Advancement) and Ability Skills (5th Advancement).

Extra DMG DEF

A defensive Stat that can defend against Extra DMG (Nuke, Bolt, Wide).


1-1) Extra DMG


- There are 3 Types of Extra DMG.


Extra DMG Types

Targets

2. Ability Crystals and Ability Upgrade Stones


Ability Crystal

Item Description

A Material only Acquired from Monsters from the Hunting Grounds of Burning Kethotum Tier or above that is required for Crafting Ability Cards.

 Players can Obtain 1 Ability Crystal and 4 Ability Crystals (Bound) per Character each Day.

Ability Upgrade Stone

Item Description

A material required for increasing Ability Card levels that can be Obtained through crafting using Ability Crystals as Materials or Salvaging Ability Cards.
