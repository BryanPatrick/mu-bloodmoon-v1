Event Map Square

Event Map Square

Introduction

  • - The event map of MU has been updated.
  • - Enjoy the new event map that has become more convenient!
  • - Event map of Chaos Castle, Blood Castle, Devil Square, Illusion Temple, Doppelganger, and Fortress of Empire Guardians has been updated.

Updates on Event Map Entry

Event Map Square Area

  • - Description
    • ▶ Register for most of the event map entries at the event map square.
    • ▶ Register for the entry to the following event maps: Blood Castle, Devil Square, Illusion Temple, Doppelganger, and Fortress of Empire Guardians.
    • ▶ You can only register for the event map entry at the event map square.
    • ▶ You cannot register for the entry to the event map from NPCs of each town anymore.
  • - How to Move
    • ▶ Register for most of the event map entries at the event map square.

    • < Warp Command Window (M) >
    • ▶ Open the Warp Command Window (M) and click 'Event Map Arena'.
    • ▶ You spend 20,000 Zen by clicking the button to move to the event map square area.
    • < Entrance Icon >
    • ▶ Move to the Event Map Square area through the Event Map Entrance Icon.
    • ▶ You spend 20,000 Zen for using the Entrance Icon.

Event Map Entrance Icon

  • - Description
    • ▶ The icons inform you when the event map becomes available.
    • ▶ Icons will appear when the event maps become available and disappear when the maps become unavailable.
    • ▶ Move to the Event Map Square area through the entrance icon.
    • ▶ The following entrance icons are available:
  • Icon ImageDescription
    Chaos Castle Entrance Icon
    Blood Castle Entrance Icon
    Devil Square Entrance Icon
    Illusion Temple Entrance Icon
    Doppelganger Entrance Icon
  • - Entrance Icon Location
    • ▶ Event Map Entrance Icons appear on the top left area.
  • - How to Use
    • ▶ Click the Event Map Entrance Icon when the event map becomes available.
    • ▶ Click to open the pop up window.
    • ▶ Click Confirm on the pop up window to move to the Event Map Square and register for the entry.
    • ▶ The Entrance Icon redirects you in front of the NPC in charge of the event map that you try to enter.

Additional Event Map Rewards

Mastery Box

  • - Information
    • ▶ Beside the previous event map rewards, the mastery box has been added as an additional reward.
      ※ Each event map must be master level or higher in order to get the reward.
    • ▶ The mastery box contains the new currency, Reud, and various items.
    • ▶ The mastery box is stored in general inventory and can be used by right-clicking.
    • ▶ There are 3 kinds of Mastery Box.
  • Item ImageItem NameItem Size
    Mastery Box (Minor)2x2
    Mastery Box (Standard)2x2
    Mastery Box (Greater)2x2

    → You cannot gain the mastery box if you did not satisfy the event's objective nor your
         contribution rate is low.

  • - How to Gain
    • ▶ You can gain the mastery box rewards based on your contribution rate.
      ※ The mastery box's grade differs based on your contribution rate.
      ※ The average rate of party member's contribution rate becomes the contribution
          rate for an energy fairy (with energy stat point higher than 1500).
    • ▶ The rewards are distributed from the Gremory case when the event map is closed.
    • ▶ The type of contribution differs based on the kind of event maps.
