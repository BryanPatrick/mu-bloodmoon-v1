6. New Skill Added

1) Runic Sphere

Skill Name

Runic Sphere

How to Acquire

Monster Hunting

Image

Skill Explanation

Basic Condition: 2nd Advancement, 100 of Energy

Creates explosive rune energy using rotating runes to inflict damage to the target and other enemies nearby.

2) Rune Phrase

Skill Name

Rune Phrase

How to Acquire

Elberland NPC James (Ruud Shop)

Image

Skill Explanation

Basic Condition: Requires 3rd Advancement, 1180 of Energy,
Plasma Ball skill, and 10 points in Plasma Ball Mastery.

Shoots a rune containing an explosive spell using a Magic Orb,
dealing damage to multiple targets within range.

* When casting a skill 3 times, there is a chance that a 'Special Phrase' will be activated, inflicting a [30% Defense Reduction Debuff] on the target.
(Major Boss Monsters are immune to debuffs.)
 * The best efficiency can be achieved when using 'Rune Phrase Skill' and 'Plasma Ball Skill' together.
