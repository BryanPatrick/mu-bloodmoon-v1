(1) Illusion Blade

Skill Name

Illusion Blade

Skill Requirements

Level Requirement: 25

Skill Description

Copies the Sword in the Right Hand and Summons an Illusion Blade in the Left.
 The Illusion Knight's ATK greatly Increases.

Misc Settings

Can Remove the Buff by Unequipping the Weapon or Right-Clicking the Buff Icon on the top.

Skill Image


(2) Illusion Avatar

Skill Name

Illusion Avatar

Skill Requirements

Dexterity Requirement: 900

Skill Description

Summons an Illusion of one’s self.
 Charges at enemies near the Illusion Knight and Attacks them.

Misc Settings

Unsummoned when apart a certain distance from the Illusion Knight.
Illusions do not Attack Characters in PVP.
 Cannot Use in the Chaos Castle Event Map.

Skill Image


(3) Charging Slash

Skill Name

Charging Slash

Skill Requirements

Dexterity Requirement: 80

Skill Description

The Illusion Knight quickly charges towards an Enemy
 and fires a powerful sword energy wave in a Fan-Shaped Radius.

Misc Settings

Does not charge towards Enemies within a 4-Tile Radius and fires the wave in-place.
 Charges towards Enemies outside a 4-Tile Radius.

Skill Image


(4) Wind Clave

Skill Name

Wind Clave

Skill Requirements

Dexterity Requirement: 650

Skill Description

Fires a sword energy wave in the form of a tornado at the Enemies in front.

Misc Settings

Cooldown: None

Skill Image


(5) Blade Storm

Skill Name

Blade Storm

Skill Requirements

Dexterity Requirement: 1150
 10 Wind Clave Mastery Points Required

Skill Description

Sharp illusion blades create a storm near the Character
 that inflicts AoE damage to multiple enemies.

Misc Settings

Cooldown: None
