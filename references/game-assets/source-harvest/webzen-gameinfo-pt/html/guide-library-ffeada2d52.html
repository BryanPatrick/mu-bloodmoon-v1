  1. Slayer Skill Upgrade Tree

    1. Skill Upgrade Tree

      1. The Skill Upgrade Tree UI can be accessed by pressing [Ctrl + A] by Slayers that have completed the 4th Advancement.
      2. Skill points acquired when levelling up after 4th Advancement can be used to upgrade skills.
      3. Shared options such as debuff options, debuff explosions, and passive options remain the same.
