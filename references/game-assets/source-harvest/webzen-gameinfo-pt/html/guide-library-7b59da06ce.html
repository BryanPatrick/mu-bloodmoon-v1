Skill Enhance Tree Side Option

    • 1. How to Use Skill Enhance Tree Side Options
    • 1) Side Option - Skill Enhancement Passive Option
      • (1) Skill Enhancement Passive Option
        • ① Skill Enhancement Passive Options can be unlocked, based on the total points invested in the skill enhancement slot on the left side of the Skill Enhance Tree. The unlocked options can be enhanced using skill points.
        • ② Skill Enhancement Passive Options unlock at three levels, and they can be enhanced by 10P per level (30P max).
        • ③ At each activation level, it can be enhanced by 10P per option level. When activated to Level 3, it can be enhanced to max 30P.

      • [Skill Enhancement Slot - Skill Enhancement Passive Option]

        • A) Level Conditions to Activate Skill Enhancement Passive Option (Example: Increase Max HP option)
          • (a) When a total of 20P is used in the skill enhancement slot, the Increase Max HP option unlocks, and reaches Activation Level 1. It can also be enhanced by 10P.
            When the Increase Max HP option is enhanced by a total of 10P, it becomes locked again.
          • (b) When a total of 45P is used in the skill enhancement slot, the Increase Max HP option unlocks again and reaches Activation Level 2. It can be further enhanced by 10P.
            When the Increase Max HP option is enhanced by a total of 20P, it becomes locked again.
    • 2) Side Option - Debuff Enhancement Passive Option
      • (1) Debuff Enhancement Passive Option
        • ① Debuff Enhancement Passive Options can be unlocked, based on the total points invested in the debuff enhancement slot in the Skill Enhance Tree. The unlocked options can be enhanced using skill points.
        • ② Debuff Enhancement Passive Options unlock at three levels, and they can be enhanced by 10P per level (30P max).
        • ③ At each activation level, it can be enhanced by 10P per option level. When activated to Level 3, it can be enhanced to max 30P.

Side Option Details

  • 1. Skill Enhancement Passive Option Details
  • 1) Increase Max HP
    • ① By enhancing the Increase Max HP option, you can increase your character's Max HP by the option enhancement value.
  • 2) Increase Basic DEF
    • ① By enhancing the Increase Basic DEF option, you can increase your character's Basic DEF by the option enhancement value.
    • ② The Increase Basic DEF option is a DEF option that cannot be penetrated with options such as Enemy DEF Ignore, to the extent of that option's value.
  • 2. Debuff Enhancement Passive Option Details
  • 1) Increase DMG
    • ① Provided to classes specializing DMG, this option increases your character's DMG.
      • (A) Dark Knight, Elf, Dark Lord, Rage Fighter, Grow Lancer
  • 2) Increase Magic
    • ① Provided to classes specializing in Magic, this option increases your character's Magic.
      • (A) Dark Wizard, Summoner
  • 3) Increase DMG / Magic
    • ① Provided to the classes specializing in both DMG / Magic, this option increases a character's DMG / Magic.
      • (A) Magic Gladiator
  • 4) Increase Skill DMG
    • ① By enhancing the Increase Skill DMG option, you can increase skill DMG by the option enhancement value.
  • 3. Common Option
  • 1) Add Variable Stat
    • ① If you enhance the Add Variable Stat option, you get points and a variable stat pop-up will be displayed where you can use those points.
    • ② You can directly enhance Strength, Agility, HP, and Energy stats.
      • ※ Variable Stat increases a character's basic stats, and it does not affect the stats required for equipping items, etc.
      • ※ Variable Stats enhanced by the Add Variable Stat option will also reset if the Skill Enhance Tree resets.

    • 1) Shining Peak - features changed
      • (1) Shining Peak Skill Settings

      • - The Cooldown time and Increase Skill Range options in the Shining Peak Skill Enhance Tree are now changed to Increase Range and Increase Attack Speed options.
