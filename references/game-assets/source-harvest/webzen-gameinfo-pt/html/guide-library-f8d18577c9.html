Kundun & Lemuria Skill & Equipment

1. Skill

1) White Wizard: Kundun Mephis

(1) White Wizard: Kundun uses some skills of the Dark Wizard and some exclusive skills.

Shared Skills


Earth Prison, Illusion, Hell Burst, Telekinesis, Magic Amplification,
 Power Wave, Lightning, Teleport, Ice, Tornado, Aqua Beam, Blast





Exclusive Skill


　

Magical Shot

　

Shining Bird

　

Violent Dragon

　

Spearstorm

[Magical Shot]

Skill Name

Magical Shot


Skill Requirements

Acquired upon Character Creation


Skill Description

Throws an enchanted projectile, dealing damage to the target.
 Targets affected by the projectile receive damage twice.



Misc Settings

Cooldown: None


Skill Image

　



[Shining Bird]

Skill Name

Shining Bird


Skill Requirements

Energy: 70


Skill Description

"Throws a huge bird of light created by light magic,
 dealing damage to multiple targets within the area."
 Targets affected by the bird receive damage once.



Misc Settings

Cooldown: None


Skill Image

 



[Violent Dragon]

Skill Name

Violent Dragon


Skill Requirements

Energy: 680


Skill Description

"Creates a Dragon of Light and deals damage to

the Target and surrounding enemies."
 Targets affected by the dragon receive damage twice.



Misc Settings

Cooldown: None


Skill Image



[Spearstorm]

Skill Name

Spearstorm


Skill Requirements

Energy: 1160
 Violent Dragon Mastery 10P


Skill Description

Inflicts damage to nearby enemies
 by firing a spear of light.
 Affected Targets receive DMG twice and also
 an additional instance with a 5% chance.



Misc Settings

Cooldown: 0.5 seconds


Skill Image



[Reflective Barrier]

Skill Name

Reflective Barrier


Skill Requirements

Energy: 410


Skill Description

Creates a reflective barrier for you or your allies that
 blocks DMG and returns a portion when receiving Shock DMG.



Misc Settings

Cooldown: None
Buff Applied to: All Party Members including Self
 * The Buff does not stack with the Summoner's "DMG Reflection" Skill


Skill Image

Skill Name

Basic Bless


Skill Requirements

Energy: 150


Skill Description

Increases all Stats for a period of time.
 Has a lower Stage Effect than the Elf's Bless Skill



Misc Settings

Cooldown: None
 * The Buff does not stack with the Elf's "Bless" Skill



[Basic Healing]

Skill Name

Basic Healing


Skill Requirements

Energy: 52


Skill Description

Recovers some HP.
 Has a lower Stage Effect than the Elf's Healing Skill



Misc Settings

Cooldown: None



[Basic Defense Enhancement]

Skill Name

Basic Defense Enhancement


Skill Requirements

Energy: 72


Skill Description

Increases DEF temporarily.
 Has a lower Stage Effect than

the Elf's Defense Enhancement Skill.



Misc Settings

Cooldown: None
 * The Buff does not stack with the Elf's "Defense Enhancement" Skill.



[Basic Attack Enhancement]

Skill Name

Basic Attack Enhancement


Skill Requirements

Energy: 92


Skill Description

Increases ATK and Wizardry temporarily.
 Has a lower Stage Effect than

the Elf's Attack Enhancement Skill



Misc Settings

Cooldown: None
 * The Buff does not stack with the Elf's "Attack Enhancement" Skill.


[Basic Recovery]

Skill Name

Basic Recovery


Skill Requirements

Energy: 168


Skill Description

Recovers some SD.
 Has a lower Stage Effect than the Elf's Recovery Skill.



Misc Settings

Cooldown: None



[Marble Burst]

Skill Name

Magical Shot


Skill Requirements

Acquired upon Character Creation


Skill Description

Throws an enchanted projectile, dealing damage to the target.
Targets affected by the projectile receive damage twice.
Magical Shot Cast Effect for Lemuria changes when Equipping an "Orb".



Misc Settings

Cooldown: None


Skill Image




[Marble Burst]

Skill Name

Marble Burst


Skill Requirements

Energy: 104


Skill Description

Fires an explosive energy marble at the Target
to damage it and nearby Enemies.
 Targets in the radius receive damage once.



Misc Settings

Cooldown: None


Skill Image



[Unleash Marble]

Skill Name

Unleash Marble


Skill Requirements

Energy: 700


Skill Description

Creates a mass of energy in the form of a marble at the Targeted Location
 that fires smaller energy to deal DMG per second to multiple enemies
 for a period of time.
 Targets in the radius receive damage twice.



Misc Settings

Cooldown: 10 seconds
Duration: 30 seconds
DMG: 2 instances of DMG per second


Skill Image



[Ultimate Force]

Skill Name

Ultimate Force


Skill Requirements

Energy: 1073
 Unleash Marble Mastery 10P


Skill Description

Creates a magic field at the Targeted Location
 that damages multiple enemies by firing smaller energy.
 Affected Targets receive DMG twice and also an additional instance with a 5% chance.



Misc Settings

Cooldown: None


Skill Image



2. Equippable Weapons

1) White Wizard: Kundun Mephis

(1) Can Equip the Dark Wizard's "Staff" as the Main Weapon

    and the "Magic Book" as the Sub Weapon.


2) Mage: Lemuria

(1) Can Equip the "Orb" as the Main Weapon

    and the Dark Wizard's "Shield" simultaneously as support.
