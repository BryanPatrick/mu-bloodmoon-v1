# Comunidade

Componentes do feed social e do painel administrativo da comunidade.

- `CommunityAdminManager`: operacao centralizada por permissoes.
- `CommunityToolbar`: busca e filtros.
- `CommunityAction`: acao operacional compacta.
- `CommunityPagination`: paginacao administrativa.

As telas consomem exclusivamente a API; nenhum dado social oficial fica no bundle.
