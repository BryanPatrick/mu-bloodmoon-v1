# O que testar no Open Beta

## Conta

- [ ] Criar uma conta nova.
- [ ] Fazer login e logout.
- [ ] Testar a recuperação de senha (se disponível).

## Launcher

- [ ] Baixar e abrir o Launcher.
- [ ] Verificar se ele atualiza sozinho.
- [ ] Entrar no jogo pelo Launcher.

## Personagem

- [ ] Criar um personagem.
- [ ] Testar diferentes opções disponíveis na criação.

## Progressão

- [ ] Subir de nível até 400.
- [ ] Dar um Reset e confirmar os pontos recebidos.
- [ ] Tentar `/masterreset` (esperado: não funcionar hoje -- isso é esperado, não um bug).

## Eventos

- [ ] Testar o Leilão (o único evento confirmado ativo).
- [ ] Testar `/participar` com os nomes de evento conhecidos e confirmar que a maioria não está disponível hoje (esperado).
- [ ] Verificar o painel de eventos (tecla D) e a agenda (tecla H).

## Comandos

- [ ] Testar `/reset`, `/masterreset`, `/participar`.
- [ ] Reportar qualquer outro comando que funcione ou não funcione como esperado.

## Trade

- [ ] Testar troca de itens com outro jogador, se disponível.

## Market

- [ ] Explorar o sistema de Market e reportar como ele funciona -- isso nos ajuda a documentar melhor.

## Guild

- [ ] Criar uma guild.
- [ ] Convidar outro jogador.
- [ ] Testar transferência de liderança.
- [ ] Testar encerramento (disband).

## Comunidade

- [ ] Explorar o perfil e feed de comunidade no portal.

## Wiki

- [ ] Usar a Wiki (quando publicada) para procurar informações e reportar o que não encontrar.

## Reportando bugs

- [ ] Usar o template de Bug Hunters para qualquer problema encontrado.
- [ ] Incluir prints/vídeos sempre que possível.

---

**Obrigado por participar do Open Beta!** Cada teste ajuda a deixar o Blood Moon melhor para o lançamento.
