# Reportando Bugs (Bug Hunters)

Encontrou algo que parece errado? Antes de reportar:

1. Confira a Central de Eventos -- muita coisa que parece "quebrada" é na verdade um evento ainda não ativado no servidor, não um bug.
2. Se ainda parecer um bug de verdade, preencha o formulário de report com: título, categoria, personagem, data/hora, mapa (se aplicável), o que aconteceu, o que você esperava que acontecesse, passos para reproduzir, com que frequência acontece, e se possível um print ou vídeo.

Ver o template completo de campos em `bug-report-template.md` (uso interno de suporte).

`PRODUCT_REQUIRED`: recompensas do programa Bug Hunters (pontos, prêmios) ainda não foram definidas -- esta página não promete nenhuma recompensa específica até isso ser decidido pelo time.
